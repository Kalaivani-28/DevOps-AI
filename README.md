# 🤖 DevOps AI – Intelligent Incident Analyzer

DevOps AI is an AI-powered incident management and monitoring platform designed to help DevOps teams detect, analyze, and resolve infrastructure and application incidents efficiently.

## 🚀 Features

- 📊 Interactive DevOps Dashboard
- 🤖 AI-powered incident and log analysis
- 🔍 Root-cause detection
- ⚠️ Incident creation, tracking, and resolution
- 🚨 Real-time alerts and notifications
- 🖥️ Microservice health monitoring
- 📈 Incident analytics and reports
- 📥 CSV report export
- 👤 User profile management
- ⚙️ Configurable application settings
- 🌙 Dark mode
- 🔐 Login and session management
- 🧠 Local rule-based fallback analysis when the AI service is unavailable

## 🏗️ System Architecture

The application is organized into separate services:

React Frontend → Spring Boot Backend → PostgreSQL Database

React Frontend → Python AI Service

Docker Compose is used to run the frontend, backend, AI service, and PostgreSQL database as independent containers.

## 🎯 Objective

The main objective of DevOps AI is to reduce the time required to investigate incidents by combining centralized monitoring, automated log analysis, root-cause identification, alerts, and recommended remediation actions in a single platform.
